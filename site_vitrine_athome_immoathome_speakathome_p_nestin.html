Guide de mise en ligne pratique

Lier vos noms de domaine OVH à GitHub Pages

Suivez ce guide étape par étape pour publier ce site gratuitement sur GitHub Pages avec vos domaines OVH (ex: immoathome.fr et speakathome.fr).

1

Créer le dépôt GitHub

Créez un compte gratuit sur GitHub.com, puis créez un dépôt public nommé :
votre-pseudo.github.io

2

Importer le fichier HTML

Dans votre dépôt GitHub, cliquez sur Add file > Upload files et déposez ce fichier sous le nom strict :
index.html

3

Activer GitHub Pages

Allez dans Settings > Pages sur GitHub.
Sous Branch, sélectionnez main (ou master) puis sauvegardez.

4

Configurer les DNS chez OVH

Connectez-vous à votre espace OVHcloud > Zone DNS et ajoutez les IP GitHub Pages ci-dessous.

Enregistrements DNS à ajouter dans la Zone DNS OVH :

1. Ajoutez 4 enregistrements de type A vers les IP GitHub Pages :

185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

2. Pour le sous-domaine www, ajoutez un enregistrement CNAME :

Cible : votre-pseudo.github.io.
